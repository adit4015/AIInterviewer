AI Mock Interview Platform 🎯

An end-to-end, full-stack AI-powered interview preparation platform designed to help candidates practice technical and HR interview rounds. The platform parses uploaded resume PDFs, generates personalized question sets, provides real-time intelligent feedback, and manages access via a credit-based monetization model powered by Razorpay.

---

## ✨ Features

- **📄 Resume Parsing:** Upload resume PDFs to auto-extract context and generate highly tailored interview questions.
- **🤖 AI-Driven Question Generation:** Dynamic generation of technical and HR question sets tailored to user experience and target roles.
- **⚡ Real-Time Feedback & Scoring:** Automated evaluation of candidate responses with actionable feedback for skill improvement.
- **💳 Credit-Based Monetization System:** Secure credit wallet architecture allowing users to purchase interview credits via Razorpay.
- **🔒 Secure Authentication:** Single-Sign-On (SSO) and robust user session management via **Firebase Google Authentication**.
- **🎨 Interactive UI/UX:** Responsive interface built with **React** and animated smoothly using **Framer Motion**.
- **☁️ Cloud Deployment:** Full-stack deployment on **Render** with optimized RESTful API routes.

---

## 🛠️ Tech Stack

### **Frontend**
- **Framework:** React.js
- **Animations:** Framer Motion
- **Styling:** CSS3 / Tailwind CSS

### **Backend**
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Authentication:** Firebase Admin SDK / OAuth 2.0
- **Payment Gateway:** Razorpay API

### **Deployment & Tools**
- **Hosting:** Render
- **Version Control:** Git & GitHub
